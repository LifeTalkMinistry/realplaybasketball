# Real Play World Player Bars

World leaderboard/player-row visual assets live here.

## Structure

- `default/` — neutral/default player-row bars.
- `ranking/` — ranking-specific player-row bars.
- `badge-dominant/` — player-row bars where a recognition/eligibility badge is the dominant visual treatment.

## Badge-dominant naming

Use lowercase kebab-case filenames based on the badge/state, for example:

- `captain-eligible.png`
- `overall-mvp.png`
- `team-mvp.png`
- `lethal-shooter.png`

Keep these assets transparent and use consistent canvas dimensions/placement so World rows do not shift when the active bar changes.
